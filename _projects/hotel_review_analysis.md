## Overview

**Hotel Review Analysis on Machine Learning and Deep Learning Based on Pre-trained GloVe Embedding** is a Natural Language Processing project focused on analyzing hotel reviews and exploring how textual sentiment can support lodging-related recommendations.

The project was completed as part of **CSE431 — Natural Language Processing** at BRAC University under the supervision of **Annajiat Alim Rasel**.

The work investigated both traditional machine learning and deep learning approaches while using **pre-trained GloVe word embeddings** to represent textual information.

## Project Motivation

Online hotel reviews contain valuable information about customer experiences, satisfaction, and preferences.

However, review data is unstructured and often difficult to analyze manually at scale.

The project explored how Natural Language Processing and sentiment analysis can be used to extract useful information from hotel reviews and support the development of a recommendation-oriented system.

## Natural Language Processing Workflow

The project involved preparing textual review data for machine learning and deep learning models.

The overall workflow included:

- Text preprocessing
- Preparing review data for analysis
- Feature extraction
- Text representation
- Use of pre-trained GloVe embeddings
- Machine learning model evaluation
- Deep learning model evaluation
- Comparative performance analysis

## GloVe Word Embeddings

A major component of the project was the use of **pre-trained GloVe embeddings**.

GloVe provides numerical vector representations of words based on relationships learned from large text corpora.

Using pre-trained embeddings allowed the models to incorporate semantic relationships between words instead of treating individual words as completely independent features.

## Machine Learning and Deep Learning

Multiple machine learning and deep learning approaches were investigated for analyzing hotel-review text.

The models were compared to understand how different approaches handled textual patterns and sentiment information.

Among the evaluated approaches, the **RNN-LSTM architecture provided the strongest performance**.

The recurrent architecture was useful for modeling sequential information in the review text and capturing relationships between words across a sentence or review.

## Sentiment-Based Recommendation

The project also explored how sentiment extracted from hotel reviews could contribute to a **lodging recommendation approach**.

Rather than relying only on structured hotel attributes, textual experiences shared by previous customers can provide additional information about the perceived quality of a hotel.

This makes sentiment analysis useful for understanding user experiences and potentially supporting recommendation decisions.
