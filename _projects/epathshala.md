## Overview

**E-Pathshala** is a full-stack e-learning platform designed to support the complete learning and course-purchasing workflow in one application.

The platform allows users to explore courses, search for content, manage a shopping cart, purchase courses, apply vouchers, download receipts, maintain personal profiles, interact with other users, and save content for later.

It also provides functionality for teachers to publish courses and vouchers.

## Key Features

- Course and product browsing with individual item views
- Search functionality
- Trending course/product display
- Shopping cart management
- Course ordering and payment workflow
- Purchased-course management
- Voucher creation and application
- Downloadable receipts and PDF generation
- Personal profile management
- Friend profiles and friend-list management
- Add, remove, and search for friends
- Watch Later functionality
- Teacher course publishing
- Voucher publishing
- User-specific order and purchase history

## Technology Stack

- **Backend:** PHP, Laravel
- **Framework:** Laravel 10
- **Frontend Build Tool:** Vite
- **Database:** MySQL
- **PDF Generation:** Laravel DOMPDF
- **Authentication / API Support:** Laravel Sanctum
- **Version Control:** Git and GitHub

## What I Worked On

I worked on designing and developing the application as a complete web-based learning platform, connecting multiple user-facing and backend features into a unified system.

The project involved implementing course discovery and purchasing functionality, user account features, social interactions, order management, voucher handling, and teacher-side course publishing.

A major focus of the project was connecting individual features into an end-to-end workflow in which users could discover a course, add it to their cart, complete an order, make a payment, and later access their purchased courses.

## Major Functional Areas

### Course Discovery

Users can browse available content, view individual courses or products, search for relevant items, and explore trending content.

### Shopping and Purchasing

The platform supports adding and removing items from a shopping cart, placing orders, processing payments, viewing previous orders, and accessing purchased courses.

### Voucher System

Users can apply vouchers during the purchasing process, while authorized users can create and publish vouchers.

### User and Social Features

Users can maintain their own profiles, view other user profiles, search for friends, manage friend lists, and view courses purchased by friends.

### Watch Later

Users can save courses or content for later viewing and manage their saved items.

### Teacher Functionality

Teachers can publish courses through the platform, allowing E-Pathshala to support both learners and course providers.

### Receipt and PDF Generation

The platform supports downloadable purchase receipts and PDF generation for transaction-related documents.
